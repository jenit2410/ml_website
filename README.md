# 🧠 ML Website – Train and Test Machine Learning Models with Tkinter

This project provides an interactive GUI-based web app (built with Tkinter) to demonstrate how various machine learning models can be used for **classification** and **regression** tasks. It’s an educational tool for beginners or students to learn how to load data, preprocess it, train models, evaluate them, and visualize the results.

---

## 📦 Features

- Load and preview CSV datasets
- Choose between Classification or Regression modes
- Select from multiple ML models (e.g., SVM, Decision Tree, Linear Regression, etc.)
- Split data into training and test sets
- Train models and view accuracy/score
- Simple, user-friendly Tkinter-based GUI
- Uses real-world example datasets (CSV files included)
